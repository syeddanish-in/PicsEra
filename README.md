# PicsEra - Photography Portfolio Website

A responsive single-page photography portfolio website built using **HTML5 and CSS3**.

## Features

* Responsive photography image gallery
* CSS Grid for the gallery layout
* Flexbox for navigation and content alignment
* `object-fit: cover` for consistent image sizing
* Semantic HTML5 landmarks
* Contact / Book a Shoot section
* Custom CSS variables for colors
* Responsive design with no horizontal scrolling
* No frameworks or external CSS libraries

## Technologies

* HTML5
* CSS3
* Git & GitHub

## Project Requirements

* Single-page responsive website
* One `<h1>` heading
* Working navigation links
* Global `box-sizing: border-box`
* Real use of CSS Grid and Flexbox
* Small, meaningful Git commits
* Mobile, tablet, and desktop support

## Note

AI tools such as ChatGPT may be used during development, but all code is reviewed and understood by the team.
